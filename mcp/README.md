# MCP는 필요할 때만 연결

MCP는 AI가 외부 문서나 도구에 접근하도록 연결하는 규약입니다. 이 키트의 스킬·설치·검증은 MCP 없이 동작합니다. 설정 예시를 넣어두었지만 자동 설치하거나 활성화하지 않습니다.

## 선택 기준

| 필요 | 우선 사용할 방법 | MCP를 검토할 때 |
| --- | --- | --- |
| 로컬 파일 분석 | 터미널과 Python | 기본 도구로 접근할 수 없는 승인된 데이터 소스가 있을 때 |
| 라이브러리 사용법 | 설치된 코드·공개 공식 문서 | 반복 검색을 줄여야 하고 문서 연결이 허용될 때 |
| UI 확인 | 플랫폼 미리보기·기존 테스트 | 브라우저 자동화가 허용되고 실제 필요할 때 |
| 외부 서비스 연동 | 과제에서 허용한 인터페이스 | 해당 계정·접근 권한·데이터 전송이 모두 허용될 때 |

## 선택적 문서 서버 예시

`codex-config.example.toml`은 공개 OpenAI 문서 검색용 서버 설정입니다. 일반 개발 문서나 사내 문서를 검색하는 서버가 아닙니다. 필요한 경우에만 실제 프로젝트 `.codex/config.toml`에 해당 항목을 합칩니다. 기존 파일 전체를 덮어쓰지 마세요. 프로젝트 설정은 신뢰 설정과 관리 정책에 따라 적용되지 않을 수 있습니다.

`codex mcp list`로 등록 여부를 확인하고, 세션에서 일반 기술 질문으로 실제 연결을 확인합니다. 등록됨과 연결 성공은 서로 다릅니다. 이 레포에서는 실제 MCP 연결을 검증하지 않았습니다.

시험 환경에서는 운영 규칙을 먼저 확인하세요. 읽기 전용 서버라도 검색어는 외부로 나갑니다. 과제 내용·데이터·코드·회사 내부 정보를 질의에 포함하지 마세요. 연결이 실패하면 로컬 자료로 계속하고, 플랫폼의 인증·보안 설정을 우회하지 마세요.
