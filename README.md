# AI 해커톤 작업 키트

문제를 받은 뒤 **요구사항 확인 → 최소 기능 구현 → 실제 검증 → 제출**까지 진행하는 개인 작업 도구입니다. 문제나 정답, 특정 기술 스택을 미리 가정하지 않습니다.

## 내일 시작하기

과제 README가 있는 폴더에서 이 레포를 `.hackkit`으로 clone한 뒤 실행합니다. 오늘 작성한 준비 파일을 GitHub에 올려두어야 내일 내려받을 수 있습니다.

```bash
git clone https://github.com/sumin819/skills.git .hackkit
python3 .hackkit/scripts/install.py --target .
```

Python 3.9 이상이면 설치와 하네스를 사용할 수 있습니다. 추가 패키지나 API 키가 필요하지 않습니다. 설치는 기존 `AGENTS.md`를 보존하면서 안내를 추가하고, Codex가 읽는 `.agents/skills/`에 스킬을 복사합니다. 기존의 다른 스킬은 건드리지 않습니다. 같은 이름의 파일 내용이 다르면 덮어쓰지 않고 중단합니다.

설치 후 새 Codex 세션을 열고 아래 문장을 보내세요. 스킬이 목록에 안 보이면 `AGENTS.md`와 해당 `SKILL.md` 경로를 직접 읽도록 요청해도 됩니다.

```text
AGENTS.md와 .hackkit/CONTEXT.md를 읽어줘.
과제 원문과 제공 파일을 확인하고 $hackathon-start로 시작해.
확정된 요구사항과 가정을 나누고, 담당자에게 물을 가장 중요한 질문을 정리해줘.
채점 기준에 연결되는 최소 기능 하나부터 구현·실행·검증해줘.
과제에서 문서를 지정하지 않았다면 결정과 결과는 PRD.md에 짧게 남겨줘.
```

이 레포 자체에서 연습한다면 `AGENTS.md`를 읽도록 요청하면 됩니다. 실제 시험 파일은 공개 준비 레포에 넣지 마세요. 설치 도구가 만드는 `.gitignore` 구간은 키트와 로컬 로그를 제외하는 편의 기능이며, 외부 전송을 차단하는 보안 기능은 아닙니다.

## 구성

| 파일 / 폴더 | 쓰임 |
| --- | --- |
| `AGENTS.md`, `CONTEXT.md` | 공통 작업 지침과 현장에서 확인할 조건 |
| `skills/hackathon-start` | 문제 해석, 성공 기준, 시간 배분 |
| `skills/stakeholder-questions` | 담당자 질문과 답변을 요구사항으로 변환 |
| `skills/build-slice` | 가장 작은 동작 단위 구현과 디버깅 |
| `skills/analyze-data` | 데이터 품질, 기준선, 누수 없는 평가 |
| `skills/verify-deliver` | 요구사항별 검증과 제출 준비 |
| `skills/explain-decisions` | 구조·선택·한계를 본인이 이해하도록 설명 |
| `templates/PRD.md` | 요구사항·결정·검증·실행법을 한 문서에 기록 |
| `prompts/` | 시작·중간 복구·마무리에 복사할 요청 |
| `scripts/checks.py` | 명령 실행, 시간 제한, 결과와 로그 저장 |
| `mcp/` | 필요할 때만 쓰는 MCP 설정 예시와 선택 기준 |

## 검증 하네스

하네스는 **검증 명령을 일정한 방식으로 실행하고 결과를 남기는 도구**입니다. AI 호출이나 무한 자동 반복 기능은 없습니다.

```bash
# 설치하지 않고 키트 자체 점검
python3 -m unittest discover -s tests -v

# 하네스 사용 예제: 실제 과제의 테스트는 아님
python3 scripts/checks.py --config examples/checks.json --root . --output .runs/demo

# 실제 과제에서는 checks.json을 과제의 실행/검증 명령으로 작성
python3 .hackkit/scripts/checks.py --config checks.json --root . --output .runs/final
```

`examples/checks.json`의 명령을 실제 테스트·빌드·입출력 검증 명령으로 바꾸세요. 명령은 문자열 배열이며 셸을 거치지 않습니다. 파이프나 리다이렉션 대신 별도 스크립트를 사용하세요. Python 명령 첫 항목은 `{python}`으로 적으면 현재 인터프리터를 사용합니다. 작업 디렉터리는 `--root`입니다. 실행할 때마다 출력 폴더 안에 고유한 기록 폴더가 생깁니다.

종료 코드 0은 설정된 검증 통과, 1은 검증 실패, 2는 설정 오류입니다. 통과는 지정한 검증의 결과일 뿐 전체 요구사항 충족을 보장하지 않습니다. 실행 명령과 로그에는 입력 데이터가 포함될 수 있으므로 로컬에서만 보관하세요. 하네스 자체는 외부 통신을 하지 않지만, 하네스로 실행한 명령의 권한·통신을 제한하지는 않습니다.

## 오늘 해둘 것

1. 모의 문제로 설치 → 스킬 사용 → 실행 → 제출 설명까지 한 번 연습합니다.
2. 내일 허용 모델, 시간, 네트워크·MCP·브라우저 사용 조건을 확인합니다.
3. 준비 파일만 검토해서 본인 GitHub에 올립니다. 현재 작성된 파일은 자동 commit/push되지 않습니다.

시험에서는 제공 지침이 우선입니다. 외부 연결이 필요한 MCP는 기본으로 켜지 않으며, 구체적인 시험 문제·데이터·결과물을 검색어나 외부 API에 보내지 않습니다. 후속 평가에서 AI가 금지되면 이 키트의 AI 도움도 사용하지 않습니다.
