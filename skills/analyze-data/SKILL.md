# 데이터로 확인하고 기준선과 비교하기

원본은 보존한다. 처음에는 파일 크기, 인코딩, 열 이름, 자료형, 행 수, 결측, 중복, 단위, 시간 범위와 식별자를 확인한다. 큰 파일은 표본이나 청크로 읽고 모든 데이터를 대화에 출력하지 않는다.

분석 질문과 지표를 연결한다. 단위와 분모를 명시하고 결측값을 자동으로 0으로 바꾸지 않는다. 제외한 데이터와 이유를 기록한다. 결과 숫자는 실행한 코드에서 산출하고 상관관계를 원인으로 단정하지 않는다.

제조 데이터라면 실제 열이 있는 경우에만 다음을 확인한다.

- lot·wafer·장비·제품별 집계 단위가 섞였는가.
- 측정 시점, 공정 순서, 레시피 변경으로 비교 조건이 달라지는가.
- 수율·불량률의 분모가 같은가. 재작업이나 중복 측정이 있는가.

예측 문제가 아니면 모델 학습을 추가하지 않는다. 예측이 필요하면 평균·최빈값·직전값·단순 규칙 등 적절한 기준선을 먼저 측정한다. 시간순 또는 그룹 단위 분할을 적용하고, 동일 개체나 미래 정보가 학습과 평가 양쪽에 새지 않도록 한다. 전처리도 학습 데이터에서만 적합한다.

불균형 문제는 정확도만 보고하지 않는다. 현업에서 중요한 오탐·미탐 비용과 정밀도·재현율 등 적절한 지표를 선택한다. 작은 데이터의 결과를 일반화하지 말고 검증 구간·표본 크기·한계를 남긴다.

산출물은 재실행 가능한 분석 코드, 필요한 결과 표·그림, 핵심 결론과 한계다. 그래프는 질문에 답하는 것만 만들고 축·단위·비교 기준을 표시한다. 설치되지 않은 도구가 꼭 필요하지 않으면 이미 있는 도구로 진행한다.
