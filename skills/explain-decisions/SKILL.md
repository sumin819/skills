# 본인이 설명할 수 있게 정리하기

실제 코드와 기록을 읽고 설명한다. 구현하지 않은 구조나 측정하지 않은 효과를 채워 넣지 않는다. 사용자가 요청한 수준에 맞춰 다음 내용을 연결한다.

- 어떤 업무 문제를 해결하고 무엇을 성공으로 정의했는가.
- 입력이 어느 파일·함수를 거쳐 어떤 결과로 나오는가.
- 검토한 대안과 현재 구조를 선택한 이유는 무엇인가.
- 어떤 입력으로 확인했고 무엇은 확인하지 못했는가.
- 어디서 실패할 수 있고 시간이 더 있다면 무엇부터 개선할 것인가.

처음에는 핵심 구성 3~5개와 데이터 흐름으로 설명하고, 필요할 때 관련 파일 위치를 보여준다. 기술 이름을 외우게 하기보다 문제·선택·증거를 연결한다.

허용된 사전 연습을 요청하면 한 번에 한 질문을 하고 사용자의 답을 기다린다. 답변의 사실관계를 코드와 대조하고 빠진 근거를 짚는다. 단순 암기용 모범 답안으로 대신하지 않는다.

실제 AI 금지 평가가 시작되었다면 답안 작성·첨삭·연습을 중단한다. 평가 중인지 불명확하고 실시간 시험 답변 요청으로 보이면 먼저 확인한다.
